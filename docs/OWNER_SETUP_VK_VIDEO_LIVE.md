# Настройка VK Видео Live для StreamToolByShwedsky

Эта инструкция нужна только один раз для подключения реального канала VK Видео Live.

## Что понадобится

- аккаунт VK / VK Видео Live владельца канала;
- доступ к кабинету разработчика VK Видео Live: https://dev.live.vkvideo.ru/;
- portable-сборка StreamToolByShwedsky Phase 3 или новее.

## 1. Создать приложение VK Видео Live

1. Откройте `https://dev.live.vkvideo.ru/` и войдите через VK ID.
2. Откройте раздел приложений.
3. Создайте приложение для StreamToolByShwedsky.
4. В список разрешённых OAuth Redirect URI добавьте **точно**:

   `http://127.0.0.1:43187/api/platforms/vk-live/oauth/callback`

Dashboard StreamTool по-прежнему работает на автоматически выбранном свободном порту. Порт `43187` используется только как стабильный локальный OAuth callback для VK.

## 2. Получить реквизиты приложения

После создания приложения понадобятся:

- Client ID;
- Client Secret.

Client Secret является секретом.

**Не отправляйте Client Secret в чат, GitHub issue/PR, мессенджер или скриншот.**

Он вводится только локально в StreamToolByShwedsky на компьютере владельца канала.

## 3. Настроить StreamToolByShwedsky

1. Распакуйте portable ZIP.
2. Запустите `START_STREAMTOOL.cmd`.
3. В браузере откройте `Настроить VK`.
4. Сверьте показанный Redirect URI — он должен быть:

   `http://127.0.0.1:43187/api/platforms/vk-live/oauth/callback`

5. Введите Client ID.
6. Введите Client Secret.
7. Нажмите `Сохранить настройки VK`.
8. Нажмите `Подключить VK`.
9. Нажмите `Открыть VK` и подтвердите доступ на официальной странице VK Видео Live.
10. После успешной авторизации браузер вернётся в StreamToolByShwedsky.

## Что StreamTool получает после подключения

Текущая интеграция рассчитана на чтение аналитики канала/стрима:

- LIVE / OFFLINE;
- зрители Online;
- подписчики канала, если поле доступно в API;
- просмотры текущего стрима;
- реакции;
- название;
- категория;
- время начала стрима, если поле доступно.

Отсутствующая необязательная метрика отображается как недоступная (`null` внутри приложения), а не как ложный `0`.

## Где хранятся реквизиты

Локальное состояние VK хранится только в профиле Windows пользователя, в каталоге StreamTool под `%LOCALAPPDATA%`.

Browser-facing API StreamTool не возвращает Client Secret, access token или refresh token. CI отдельно проверяет это свойство.

Для будущего публичного распространения хранение секретов должно быть перенесено за Windows DPAPI / Credential Manager или внешний OAuth broker. Текущий вариант рассчитан на личное/семейное использование StreamTool.

## Если подключение не открывается

### Порт 43187 занят

StreamTool покажет ошибку. Закройте программу, которая занимает порт `43187`, и повторите `Подключить VK`.

### VK сообщает о неверном redirect URI

Убедитесь, что в приложении VK зарегистрирован **точно** этот адрес, без лишнего `/` в конце:

`http://127.0.0.1:43187/api/platforms/vk-live/oauth/callback`

### Авторизация устарела

StreamTool переведёт VK в состояние `переподключить`. Повторите `Подключить VK`; историю прошлых стримов это не удаляет.
